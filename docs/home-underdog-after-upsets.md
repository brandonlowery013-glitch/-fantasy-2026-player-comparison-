When both teams won their most recent game as moneyline underdogs and the current home team is the moneyline underdog, select the home team for the moneyline direction. This is a selection exception, not a new probability estimate or automatic bet.

The scheduled moneyline collector rebuilds evidence from the current producer ledger on each refresh. Both prior games require verified final settlements and saved two-sided pregame odds. Missing evidence, a prior loss/tie, equal current prices, an away underdog, or a completed current game cannot activate it. Team names, game IDs and week numbers are not hardcoded. Byes use the most recent game.

Keep calibration, probabilities, betting thresholds, spread, total and historical picks unchanged. Browser rendering honors the server's exception selection and displays the existing probability for that side. The numerical explanation retains the base model contributions and identifies the selection reason separately.
