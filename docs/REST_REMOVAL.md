# User-requested removal of days of rest

Future scoring uses scoring-decay-no-rest-2026-v2. Both standardized rest coefficients are disabled; raw zero alone would leave a centering effect. The scoring coefficients, intercept, taper, venue and historical artifact remain unchanged. Rest inputs are neither required nor collected by the refresh path when this policy is active.

This is a user-requested ablation in shadow mode, not a newly validated model. The original held-out residual distribution remains an estimate from the base model; the no-rest variant needs prospective calibration. No automatic actionable promotion occurs.

The narrowly scoped cached-input conversion verifies the original forecast attribution and source hash, refuses expired inputs, and preserves started games. Original issued picks and settlements are not rewritten. Subsequent captures have a new model version and publication time.

The saved NYG example was intercept 2.06254599 + scoring matchup 3.24556628 + centered rest -0.00112002 = margin 5.30699225. The 2.15108045 venue contribution is already within the scoring matchup and must not be added twice. Equal-rest centering also contributed 0.13014388 to the old total. Both rest terms are removed prospectively. This does not establish a dedicated O/U formula.
