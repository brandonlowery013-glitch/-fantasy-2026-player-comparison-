# Draft Opportunity UI Integration

The QA-locked 162-player draft Opportunity layer is a season-long acquisition companion. It is rendered on Player Board, Player Profile, and Compare. It does not independently change projections, Player Quality, or Our Draft Rank and it does not feed Weekly Opportunities, game probabilities, or sportsbook EV.

Primary navigation is Player Board | Compare | Weekly | Games. Player Profile is an internal drill-down, Player Props are nested under Games, and Weekly Opportunities are nested under Weekly.
